# Netflix Content Analysis - Power BI Dashboard

## Project Overview
Analyzed 8000+ Netflix titles to find content trends, genre performance and release patterns.

## Tools Used
- SQL (MySQL) - Data Cleaning
- Power BI - Dashboard
- Excel - Initial Analysis

## Key Insights
- 70% content is Movies, 30% TV Shows
- Most content added in last 3 years
- USA produces highest content
